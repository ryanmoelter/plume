# Plume formatting skill

Skill content teaching Claude Code how to format output for Plume's chat
renderer — tables, lists, and mermaid diagrams sized for a narrow vertical
column. Installation is not wired up yet: nothing in the app copies this
skill into `~/.claude/skills` or passes it to a launched session. See the
"Running inside Plume" item in `docs/roadmap.md` for what remains.
